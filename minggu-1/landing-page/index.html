Kurikulum 12 minggu

Minggu 1-2: HTML dan CSS

Dasar halaman web dan tampilan responsif.

Minggu 3-4: JavaScript

Logika dasar dan interaksi di browser.

Minggu 5-6: PHP

Pemrograman sisi server.

Minggu 7-8: Laravel

Framework untuk aplikasi web lengkap.

Minggu 9-10: Database

MySQL, relasi tabel, dan query.

Minggu 11-12: Project akhir

Membangun dan men-deploy aplikasi sendiri.
